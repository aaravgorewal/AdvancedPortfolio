## Tech Stack

This repository is built with a modern, performance-focused stack:
- **Next.js (16.3)** — App Router, static generation, server components
- **React (19)** — Core UI library
- **TypeScript** — Strict type safety
- **Tailwind CSS (v4)** — Utility-first styling
- **Framer Motion** — Complex, physics-based scroll and hover animations
- **Lucide React** — Minimalist iconography

---

## Design & Experience

The portfolio's visual identity relies on strict structural constraints and premium typography rather than excessive decoration:
- **Cinematic hero reveal:** Controlled entrance animations focusing on typography and spacing.
- **Editorial typography:** Utilizing Syne (headings) and Sora (body) for a highly legible, premium aesthetic.
- **Dark visual system:** Near-black backgrounds combined with cream/off-white text to reduce eye strain.
- **Amber accent:** Highly restrained accent color (`#E8913C`) used strictly for active states and critical indicators.
- **Sticky navigation:** Unobtrusive, auto-centered header navigation.
- **Scroll-based interactions:** Hardware-accelerated viewport entrance physics.
- **Responsive layouts:** Rigid mathematical CSS grid constraints ensuring typography never blows out or eclipses imagery.
- **Interactive hover states:** Subtle scaling, targeted translations, and clean background blending.

---

## Portfolio Features

- **Responsive Navigation:** Centered layout gracefully degrading to mobile viewports.
- **Animated Catalogue:** Alternating two-column project grids on desktop (Text Left / Image Right -> Image Left / Text Right).
- **Museum-Framed Screenshots:** Images use structured padding and `object-contain` within strict borders to preserve all UI elements.
- **Hover Interactions:** Minimal rotation, scaling (e.g., `1.015x`), and translation without bouncy parallax effects.
- **Back-to-Top Rocket:** A signature, fixed bottom-right scroll utility featuring a custom hover glow and launch sequence.
- **Custom Favicon:** A mathematically drawn monogram (`[A.]`) compiled statically by Next.js.
- **Accessibility:** Respects OS-level `prefers-reduced-motion` settings and utilizes ARIA labeling for focus states.

## Local Development

To run this project locally, clone the repository and install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

The application will be available locally at `http://localhost:3000`.

---

## Production Build

To generate an optimized, static production build:

```bash
npm run build
```

You can then test the production build locally using `npm run start`.
